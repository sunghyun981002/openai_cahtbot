1. 프로젝트 개요
Next.js 15과 OpenAI API를 활용하여 다양한 역할의 AI 기능을 수행하는 웹 애플리케이션을 제작한다.
기능은 다음과 같은 순서로 확장하며 개발한다.

기본 챗봇

역할 기반 AI

블로그 글 자동 작성 AI

JSON 기반 응답 처리 및 UI 시각화 AI

2. 개발 기능 명세
2.1 기본 챗봇 기능
사용자가 입력한 질문에 대해 OpenAI API를 호출하여 답변을 출력

간단한 카드형 UI 구성

대화 내역은 로컬 스토리지에 저장

라우트: /chat
구성 요소:

입력창

응답 출력창

대화 이력 저장 기능

2.2 역할 기반 AI
사용자가 역할을 선택하면 해당 역할에 맞는 시스템 프롬프트를 사용하여 AI가 답변

예시 역할: 번역가, 멘토, 의사, 상담가 등

라우트: /role
구성 요소:

역할 선택 드롭다운

역할별 프롬프트 로직 처리

대화 인터페이스 재사용

2.3 블로그 글 자동 작성 AI
사용자가 입력한 주제에 대해 블로그 글을 자동 생성

마크다운 형식으로 작성된 글을 미리보기로 제공

생성된 글 복사 및 저장 가능

라우트: /blog-writer
구성 요소:

주제 입력 폼

생성 버튼

마크다운 미리보기 창

복사 및 저장 버튼

3. 공통 사양
프레임워크: Next.js 15

언어: TypeScript

스타일링: Tailwind CSS

API 연동: OpenAI GPT 모델 사용 (필요 시 Function Calling 적용)

상태 관리: React Context API, Local Storage

UI 스타일: 반응형, 카드형 구성
